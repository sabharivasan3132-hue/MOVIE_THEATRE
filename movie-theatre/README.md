# Movie Theatre Ticket Booking and Box Office Analysis System

Scenario 30 for register numbers 30, 60, 90 and 120. A Java console application manages shows, seat counts and ticket sales in PostgreSQL. Python reads that database and generates box office charts.

## Windows setup

- Check that pgAdmin connects to PostgreSQL. If missing, install the [Windows package](https://www.postgresql.org/download/windows/) with PostgreSQL Server and pgAdmin. Use port 5432 for this configuration.
- Check `javac -version` in VS Code. If missing, install [Temurin JDK 21](https://adoptium.net/temurin/releases/?version=21), enable Add to PATH, and reopen VS Code. In Extensions, install Microsoft's Extension Pack for Java if absent.
- Check `python --version` (or `py --version`). If missing, use the [Python Windows download](https://www.python.org/downloads/windows/) and reopen VS Code.

## Run

1. In pgAdmin, create a new database named `movie_theatre`. Open Query Tool on that database. Run `sql/schema.sql`, then `sql/sample_data.sql`, once each. Run each query in `sql/reports.sql` separately to view its results.
2. Open this folder in VS Code. Wait for Maven import. Open `src/main/java/college/theatre/TheatreApp.java` and click **Run** above main. Enter your PostgreSQL password in the integrated terminal. The default user is postgres on localhost:5432. If necessary, change user and port in persistence.xml and box_office.py.
3. Choose option 5 and note the ID of the future Ocean Lights show. Option 6 books tickets; option 8 lists booking IDs; option 7 cancels a booking. See docs/Software_Engineering.docx for the demo tests.
4. Exit Java with 0. In the project terminal run:
   ```powershell
   python -m pip install -r analysis/requirements.txt
   python analysis/box_office.py
   ```
   Enter your database password. Charts appear in analysis/output.

## Rules and evidence

The demonstration records payments and refunds in PostgreSQL. Before a show starts, cancellation releases the seats and records a full refund. Booking and cancellation stop when the show starts. The app tracks the number of seats per show. Monthly occupancy divides total booked tickets by total seats offered for shows in that month.

Save screenshots of actual SQL and Java output to evidence/ and fill the Actual column in the test document. Dates and IDs depend on when the data was loaded. To submit, upload the extracted project files with the generated charts and evidence. Exclude target/ and the ZIP.
